# 计算机图形学实验2 - 3D 几何变换、四元数插值与渲染

本项目是基于 **Taichi Lang** 实现的计算机图形学基础与进阶实验。通过高性能并行计算，实现了完整的 3D 渲染管线模拟，并在基础任务（扁平三角形旋转）的基础上，进阶实现了 **3D 立方体线框模型（Wireframe Model）** 的构建，以及基于**四元数球面线性插值（Slerp）** 的多姿态平滑过渡动画。

## ✨ 技术亮点

* **高性能并行内核**: 使用 Taichi 的 `@ti.kernel` 和 `@ti.func` 实现 3D 顶点变换与矩阵运算的硬件级并行加速。
* **完整 MVP 管线**: 手写实现了完整的矩阵变换流，包括视图矩阵（View）以及透视平截头体挤压（Perspective-to-Orthographic）投影矩阵。
* **无万向节锁的 3D 旋转**: 摒弃了传统的欧拉角，引入**四元数（Quaternion）** 代数驱动三维空间旋转，彻底杜绝了万向节死锁（Gimbal Lock）现象。
* **高阶 Slerp 插值**: 实现了球面线性插值（Slerp）内核，在初始姿态 $R_0$ 和目标姿态 $R_1$ 之间拉出完美的弧形过渡路径 $R_t$，保证旋转时角速度恒定，物体不缩水、不畸变。
* **现代包管理**: 采用 `uv` 工具链，秒级构建 Python 3.12 虚拟运行环境。

## 🛠️ 环境要求

* **Python**: 3.12+
* **包管理工具**: [uv](https://github.com/astral-sh/uv)
* **依赖库**: `taichi`, `numpy` (将通过 uv 自动安装)

## 🎮 交互指南

程序启动后会弹出一个 700x700 的 GUI 窗口，默认开启自动来回旋转动画：

* **A 键**: 手动减小插值因子 `t`（物体向初始姿态 $R_0$ 靠拢，同时暂停自动动画）。
* **D 键**: 手动增大插值因子 `t`（物体向目标姿态 $R_1$ 靠拢，同时暂停自动动画）。
* **空格键 (SPACE)**: 开启或暂停自动往返（Ping-Pong）动画循环。
* **Esc 键**: 优雅地退出程序窗口。

> **色彩状态提示**: 画布上线框的颜色会随进度 `t` 动态变换。靠近起点 $R_0$ 时呈现**红色**，位于正中间 $R_t$ 时呈现**绿色**，到达终点 $R_1$ 时呈现**蓝色**。

## 🔍 实现细节说明

项目完整模拟了标准图形管线的顶点处理与空间过渡阶段：

1. **几何拓扑构建 (Topography)**: 显式定义了标准正方体的 8 个局部坐标顶点与 12 条闭合边索引，使线框渲染在并行架构下高效遍历。
2. **Model Matrix (四元数转换)**: 实时将 Slerp 插值生成的齐次四元数转化为 $4 \times 4$ 的旋转矩阵，作用于局部坐标系。
3. **View Matrix**: 将场景平移至以 `eye_pos` 为中心的相机空间。
4. **Projection Matrix**:
* 将透视平截头体挤压为长方体。
* 通过正交变换缩放至标准 NDC 空间 (Standard Cube $[-1, 1]^3$)。

5. **Perspective Division & Viewport Transform**: 对裁剪空间坐标进行透视除法（除以 $w$ 分量）得到 NDC 坐标，最后将其映射到屏幕坐标系 $[0, 1] \times [0, 1]$ 供 GUI 线段绘制。

## 🧪 实验探究：插值因子（$t$）与状态响应

通过手动调整插值步长，我们对图形管线在不同过渡状态下的矩阵表现进行了数据记录：

| 旋转进度 ($t$) | 当前四元数状态 $[w, x, y, z]$ | 核心图像视觉特征与探究发现 |
| --- | --- | --- |
| **$t = 0.0$ (起点)** | $[0.883, -0.306, -0.306, 0.177]$ | **初始状态姿态 $R_0$**。立方体整体向左上方倾斜；画面完全由纯红色主导。 |
| **$t = 0.3$** | $[0.814, -0.076, -0.076, 0.302]$ | **Slerp 插值过渡中**。立方体顺滑地沿大圆弧线向上翻转；色彩向黄绿色渐变。 |
| **$t = 0.5$ (中间态)** | $[0.729, 0.111, 0.111, 0.395]$ | **中间平衡状态 $R_t$**。多轴透视畸变在此处达到平衡；线框呈现均等的 RGB 混合色。 |
| **$t = 0.8$** | $[0.597, 0.355, 0.355, 0.485]$ | **逼近目标状态**。立方体深度方向（Z轴）压缩明显，立体透视感极强。 |
| **$t = 1.0$ (终点)** | $[0.500, 0.500, 0.500, 0.500]$ | **目标状态姿态 $R_1$**。立方体稳稳锁定在右下方倾斜视角；线框颜色完全转为纯蓝色。 |

### 💡 实验大发现

1. **透视投影（Perspective Projection）的正确性验证**: 在旋转过程中，当立方体的某个面转到最前方时，对应的棱边在屏幕坐标系下明显拉长变粗；而转到后方的棱边则按比例向中心自适应收缩。这表明手写的透视挤压矩阵（$M_{p2o}$）能够精准模拟人眼“近大远小”的真实物理视觉。
2. **刚体骨架守恒（Rigid Body Conservation）**: 在整个动画循环中，立方体的 12 条棱边在空间中均速旋转，未出现任何体积塌陷、拉伸扭曲或缩水的异样变形。这有力地证明了 **Slerp（球面线性插值）** 算法在维护旋转矩阵正交性、保持刚体几何完整性方面，具有比普通线性插值（Lerp）更高阶的优越性。
